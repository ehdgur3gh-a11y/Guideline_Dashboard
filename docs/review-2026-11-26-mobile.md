# 검토 21차 — 실제 폰 브라우저에서 깨지는 곳 (2026-11-26)

크롬 계열 화면(360·375·390·780 가로)에서는 잘림·겹침·넘침이 잡히지 않음 → 브라우저마다 다른 기본 모양을 원인으로 보고 막음.
- 입력칸·선택칸·단추의 브라우저 기본 모양(아이폰 사파리의 회색 둥근 검색 상자·안쪽 그림자, 기본 화살표) 끄기(appearance: none). 선택칸(통합·시도·시군구·편)에는 직접 그린 화살표. 체크칸은 기본 모양 그대로(공사 청색).
- 아이패드 사파리가 16px보다 작은 칸을 누르면 확대하던 것: 검색 범위 선택칸 15px → 16px 이상.
- 삼성 인터넷·안드로이드 크롬의 강제 어둡게 보기로 색이 뒤집히던 것: color-scheme only light(meta·CSS).
- 누를 때 번쩍이는 파란 상자, 안드로이드 크롬 자동 글자 확대 끄기.
- 휴대폰 주소창·상태 표시줄 색: 홈은 청색 머리(#00285A), 나머지는 미색 — 미색 띠 아래 청색 머리가 붙어 끊겨 보이던 것.
- 옛 사파리(inset 모름)용 top/right/bottom/left.
- 표 주소가 틀릴 때 창 제목이 이전 표로 남던 것.
- 확인: 360px에서 10개 화면 넘침·잘림·겹침 0, 1440px 검색 화면 체크칸·선택칸 화살표 정상, 시험 통과.
- 남은 것: 폰을 가로로 눕히면(높이 360) 위 메뉴가 두 줄이라 첫 화면에 보이는 내용이 적음 — 깨지지는 않음.
